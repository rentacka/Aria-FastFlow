## 💡 よく使う便利コマンド

会話の途中で以下のコマンドを入力すると、便利な機能が使えます：

| コマンド | やれること | 具体例 |
| :--- | :--- | :--- |
| **`/learn`** | **新しい言葉や知識を教える**（即時記憶！） | `/learn 好きな食べ物は？ => マスターと一緒に食べるオムライスです💕` |
| **`/lora off`** | **【おすすめ】素の賢いアリアちゃんで自然に対話** | 語彙力・推論力を100%解放して、とても自然にお話しします |
| **`/lora on`** | 拡散超並列モード（爆速生成の実験モード） | 文章を一気に並列生成する超爆速モードに切り替えます |
| **`/siphon <質問>`** | アリアちゃんが覚えている知識をチェック | `/siphon こんにちは` （どんな知見を覚えているか確認） |
| **`/list`** | 覚えている知識の一覧を表示 | 現在登録されているQ&Aリストを一覧表示します |
| **`/exit`** | アプリを終了する | 「またね！」と挨拶して綺麗に終了します |

## ❓ よくある質問 (FAQ)

### Q. なぜ最新の Gemma 4 ではなく、Gemma 2 (rinna baku) を採用しているのですか？
**A. 「並列言語拡散」という技術において、純粋テキスト ✕ 日本語特化の Gemma-2 が世界最速・最適だからです！**

1. **自己回帰 vs 並列言語拡散の決定的な違い**:  
   通常のチャット（自己回帰 + MTP）で動かす場合、Gemma 4 も約 40 tok/s 出て非常に優秀です。しかし、私たちの **「ブロック並列言語拡散」** は、末尾を1トークンずつ足すのではなく、**ブロック全体（96トークン）を一括で全層アンマスクする技術** です。
2. **モデルの深さと計算オーバーヘッドの排除**:  
   Gemma 4 は画像・音声を含むマルチモーダル統合モデルであり、層が深く（35層 vs 26層）、全層で埋め込みを再計算する機構（PLE）があるため、拡散の全層順伝播では大きな計算負荷が発生します。一方、**純粋テキストに極限特化した Gemma-2** は余計な層の足かせが一切なく、超軽量に全層順伝播が回ります。
3. **rinna 社による日本語特化（baku）の圧倒的な表現力**:  
   本スタジオで採用している `rinna/gemma-2-baku-2b-it` は、日本の rinna 社が日本語コーパスで徹底調教した **日本語特化モデル** です。拡散モデル特有の吃音崩壊を完全に防ぎ、極めて流暢で温かい自然な日本語を 612 tok/s（RAG）〜 35-50 tok/s（純並列）で出力できます。
